Repeated Prisoner's Dilemma Simulator

同じ2人が囚人のジレンマを繰り返す中で、 戦略や実装ミスによって協力関係が どのように維持・崩壊・回復するかを観察します。

ゲームの構造

Players

Player AとPlayer Bの2人が、 同じ相手と繰り返しゲームを行います。

Actions

各プレイヤーは毎期、 協力 C または 裏切り D を選択します。

Repetition

同じゲームを指定したラウンド数だけ繰り返します。 各戦略は過去の行動や利得を参照して次の行動を決めます。

Error

実装ミスが発生すると、 戦略が意図した行動とは逆の行動を取ります。

利得構造

Player B：C Player B：D
Player A：C 3, 3 0, 5
Player A：D 5, 0 1, 1

各セルは「Player Aの利得, Player Bの利得」を表します。

戦略

Tit for Tat

最初は協力し、その後は相手の前回行動をそのまま返します。

Forgiving TFT

Tit for Tatを基本としつつ、 相手が裏切っても一定確率で協力を返します。

Grim Trigger

最初は協力しますが、 相手が一度でも裏切ると以後ずっと裏切ります。

Win-Stay Lose-Shift

前回の結果に満足すれば同じ行動を続け、 不満なら行動を切り替えます。

Random

毎期、協力か裏切りをランダムに選択します。

2人の戦略、繰り返し回数、実装ミスの確率を設定してください。

シミュレーション結果

Statistics

シミュレーションを実行すると、 協力率や平均利得が表示されます。

累積利得の推移

各ラウンドまでに獲得した利得の合計を表示します。 線の傾きが大きいほど、その期間に高い利得を獲得しています。

見方： 2本の線が近い場合は両者が同程度の利得を獲得し、 線の差が広がる場合は一方がより高い利得を得ています。

Event Log

実装ミスや協力関係の崩壊・回復など、 ゲーム中に起きた重要な出来事を記録します。

シミュレーションを実行するとイベントが表示されます。
