# Mobile production assets

This directory is generated by `scripts/generate-production-assets.py` and
validated by `scripts/validate-production-assets.py`.

- The primary store icon uses the fixed eSlams store blue (`#1b32c4`) and the
  alpha mask from `assets/brand/mark.png`.
- Alternate icon colours are read from the six authoritative theme tokens.
  Every theme includes an opaque 1024-pixel legacy icon plus a complete Android
  adaptive set: opaque token-background image, transparent accent-mark
  foreground, and transparent white monochrome mask.
- Android adaptive foreground and monochrome assets keep the mark inside the
  adaptive safe zone.
- Runtime sounds are mono, 44.1 kHz, PCM16 WAV files. The piece-arrival
  notification additionally ships as iOS CAF and Android Ogg Vorbis.

Regenerate from the repository root after installing Python 3 and Xiph
`vorbis-tools`:

```sh
python3 apps/mobile/scripts/generate-production-assets.py
python3 apps/mobile/scripts/validate-production-assets.py
```

The manifest intentionally has no timestamp. Fixed synthesis seeds, a fixed
Ogg stream serial, and canonical JSON keep the generated hashes reproducible.
