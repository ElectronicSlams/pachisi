# Playing-card asset source

- Source: https://www.me.uk/cards/
- Generator: https://www.me.uk/cards/makeadeck.cgi
- Generated: 2026-07-26
- Options: plain ace, Goodall back, symmetric pips, modern and reverse court directions
- Licence: CC0 1.0 Universal / public domain
- Licence URL: https://creativecommons.org/publicdomain/zero/1.0/

The source explicitly permits modification and does not require attribution. These SVGs are
vendored so Arena never depends on a third-party image host at runtime.

`1B.svg` is an original eSlams replacement for the generated Goodall back. It is
a compact, restrained local SVG with no external references, gradients, or neon
colors. Copyright (c) 2026 Electronic Slams; it is distributed under the
repository's MIT License.

The generated `2B.svg` back is intentionally excluded: Arena uses only the
compact local `1B.svg` back. Runtime URLs include the immutable asset-set
version directory (`/assets/playing-cards/v1/`).
