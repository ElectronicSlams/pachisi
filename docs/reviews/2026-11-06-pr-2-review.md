## Findings resolved before merge

- **Replay identity still depended on JSON property order.** Reversing object keys in an otherwise equal chess trace produced a different key and reset playback. Identity now uses a canonical serialization with sorted object keys. Keeping the serialization also removes the possibility of two distinct traces sharing the former 32-bit hash. The browser host probe alternates property order during repeated re-renders; changed content still resets to frame zero. Shared immutable frame arrays reuse the memoized key.
- **The archive index contradicted the public repository status.** The index still described publication as pending. Both it and NOTICE now record the actual policy and edits. The 61 provider SVGs were inline markup, not data URIs; the data URIs are first-party brand PNGs. Removed the provider SVG dictionaries from the source and generated HTML, replaced provider auth icons with a generic account outline, and preserved the API's null/text fallback. An isolated asset-API smoke check confirms both archived copies match and provider aliases return null. Prior git history is unchanged.
- **Palette snapshot identity still named the original Platform palette.** `THEME_TOKEN_SNAPSHOT_VERSION` now identifies `pachisi.theme-tokens.v2`. The independent `THEME_TOKEN_REFERENCE_VERSION` and scene-envelope wire field remain `eslams.theme-tokens.v1`; changing those unilaterally would break the carried Platform contract. Tests assert both identities, and documentation explains migration of visual fixtures.
