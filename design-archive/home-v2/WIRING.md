# eSlams Home — wiring map (design → real data)

**File:** `eSlams Home v2.dc.html` + `es-data-v2.js` · **Repo:** `makriman/eslamsplatform`
Everything the page renders comes from one mock contract: **`window.ES`** (built in `es-data-v2.js`). To wire the page, replace that object's fields with API/DB-backed values; the component reads only `window.ES` and never hardcodes data (all copy-level numbers below are flagged).

Reference patterns borrowed from artificialanalysis.ai and kept intentionally: confidence bounds on every score, a visible "published" stamp, honest coverage counts ("N of M verified"), and a Methodology link beside the lens controls.

---

## 0. Global contract — `window.ES`

| Field | Shape | Wire to |
|---|---|---|
| `ES.models[]` | `{id:"openai/o3", score, p10, p90, lowerBound, winRate, games, rank}` | Leaderboard query, one row per model. `score` = **Official Score**, `p10/p90` = 80% credible interval bounds, `lowerBound` = **Rank Score** (rank by this, not the mean), `games` = **Cases**. Mock rows in `es-data-v2.js → REAL[]` were transcribed from eslams.com/leaderboard (24 Jun 2026) and will drift — replace first. |
| `ES.providers[]` | `{key, name, tier, hue}` | Providers table (70). `hue` drives the deterministic avatar color — keep server-side or derive from `key` hash. |
| `ES.games[]` | `{slug, name, category, variant, difficulty, players}` | Games catalog (50). Categories: Board 16 · Card 17 · Strategy 5 · RL 12 — the M4 group counts derive from this array, never hardcoded. |
| `ES.matches[]` | `{kind, game, a, b, status, rec, winner, result, freshness, stakes, adv}` | Recent/live matches feed. `rec` is the replay record — see §1. |
| `ES.lens{}` | per-category `{rows[], coverage}` | One leaderboard query per lens (overall + 4 categories). `coverage` string = verified-games count per category (mock: `catVerified`). |
| `ES.champions[]` | per marquee game `{id, score, p10, p90}` | Top-1 by rank score per featured game (`CHAMPS{}` map is mock). |
| `ES.stats{}` | `{games:50, providers:70, models:60, officialGames:542339, published:'24 Jun 2026', arenaGames:25, arenaVariants:38}` | Single stats rollup endpoint. `officialGames` and `published` must come from the scoring run metadata. |
